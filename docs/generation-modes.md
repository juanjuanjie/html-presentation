# 两种 HTML 生成模式

模式决定内容组织，模板决定视觉风格。同一主题可以生成演讲 HTML，也可以生成导演 HTML。

## 演讲 HTML：逐字稿 → 观点页面

完整读取逐字稿，保留事实、论证和重点，提炼标题、短句和图示。允许重新分页，不要求一段一页。备选标题列表、钩子标签等编辑标记不进入画面。采用轻量动效，由讲者手动翻页。标题和文件名以 `【演讲HTML】` 开头。

## 导演 HTML：导演稿 → 一镜一页

输入含顺序编号的镜头，每镜提供布局、画面、花字、动效、转场和口播。首页识别 `镜 01`、`镜头 01` 等标题，支持 Markdown 标题和粗体；编号从 1 连续递增，重复或跳号需先校对。

- 全文逐镜读取，页数与镜头数一致，不额外加封面或结束页。35 镜必须得到 35 页，不因内容相似而合并。
- 每页使用 `.slide`；`data-page` 保存原镜头编号但不显示。页码和进度条属于导航控件，可以保留。
- 每镜完整口播放在 `.slide-subtitle` 中，逐字保留标点。字幕可隐藏，但不能删除原文节点，否则后续字幕时间轴无法匹配。
- 展示大字去掉逗号、顿号、分号，可换行；口播字幕不适用此规则。展示中的技术缩写改为中文全称，口播保持原文。
- 仅显示观众内容，不展示镜头号、章节标记、时长、机位或动效说明。对比页统一“旧 → 新”，新状态使用模板强调色。
- 不使用真人、版权影视或动漫素材；采用文字和抽象几何图形。无音频、BGM 或音效。
- 标题和文件名为 `【导演HTML】` + 去掉 `【导演稿】` 前缀的原稿标题。另存新文件，不覆盖导演稿。

## 动效与视频渲染约定

不能仅切换 `.active` 就假定所有元素已显示。CSS 初始透明度、打字机、计数器、SVG 等可能需要各自初始化。

要求生成的导演 HTML 实现以下接口：

- `window.runSlide(slideElement)`：进入页面时重播动效，清理旧计时器。手动翻页复用同一逻辑。
- `window.presentation.goTo(index)`：零起始页索引；切页并同步页码、进度条和动效。
- `window.presentation.renderFrame(index, localSeconds)`：以页内秒数确定画面状态。相同输入产生相同结果，支持回退；覆盖 CSS、JS、SVG 动画，不依赖机器渲染速度。秒数仅作程序参数，不显示在画面。
- 静态导出模式显示当前页完整最终内容，而非同时显示所有页面。

这些是提供给 AI 的生成约定，不表示现有模板或外部录屏工具已经实现接口。接入视频工具时仍需检查调用方式；静态截图不能替代动态视频渲染。

## 交付前校对

1. 核对镜头数、DOM 页数、编号和顺序，不能只看显示的总页数。
2. 逐镜比较原文与 `.slide-subtitle`；展示文案精简不能影响口播。
3. 逐页检查进入、中段、结束状态，确认主体不残留 `opacity: 0`。
4. 检查方向键、空格、Home/End、触摸、按钮、页码、进度条及主题切换。
5. 在 1920×1080 检查边界和文字可读性，确认没有制作备注或音频。
6. 视频前先人工审核 HTML，再抽查视频翻页时间与音画同步。

## 首页工具的边界

首页仅在浏览器中整理提示词，包含稿件全文、模板源码和模式规则。不调用 AI，不自动生成或验证最终 HTML，不保存稿件。生成质量仍需校对。过长提示词可下载成文本附件交给 AI；私人稿件不应提交到公开仓库。
