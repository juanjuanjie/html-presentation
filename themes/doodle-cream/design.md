# Doodle Cream · 白纸暖黄

一套带人物插画、编号信息卡与黄色满版页面的手绘演示系统，不继承 BlockFrame 的结构或视觉语言。

## 视觉语言

- 纸张：纯白 `#FFFFFF`
- 墨色：炭黑 `#222222`
- 强调黄：暖柠檬黄 `#FFE477`
- 辅助底色：白色 `#FFFFFF`
- 字体：`Xiaolai`，回退为楷体
- 线条：4–5px、不规则圆角、无投影
- 构图：大留白、低信息密度、每页一个视觉中心

## 使用原则

1. 一页只表达一个结论。
2. 黄色只用于最重要的词或节点。
3. 辅助信息使用白底黑框，不使用紫色。
4. 不使用硬阴影、粗重面板、荧光色和新野兽派结构。
5. 动效保持轻微淡入与位移，不抢内容。

## Agent 提示词规则

> 本页“说明”相当于模板使用手册，供用户阅读；`design.md` 本身不会被首页读取，也不会直接写入复制出的 Agent 提示词。下面标为“已参与生成”的内容，表示首页生成器中已经配置了同等规则。

### 已参与生成

- 仅封面页和最后一页可以按内容需要使用整页黄色背景，并非必须使用。
- 其他所有内容页统一使用 `#FFFEFB`，包括目录、数据、案例、步骤、步骤详情、转场、对比和总结前页。
- 黄色只用于标签、数字、按钮、短下划线等小面积强调，禁止为了制造节奏交替生成黄色背景页。
- Agent 交付前需要检查所有非首尾页面的实际背景色，确保为 `rgb(255, 254, 251)`。

首页仍会另外传入 Doodle Cream 的完整 `template.html`、当前配色变量以及通用的字幕、转场、对比和生成规则。
