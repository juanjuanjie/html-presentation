# Doodle Cream · 设计说明

一套以奶油白纸张、暖黄色强调、手写字体和轻量涂鸦线条组成的演示系统。整体气质温暖、清楚、亲切，像经过认真排版的个人讲义，而不是厚重的商业模板。

本说明用于约束后续使用 Doodle Cream 制作的演讲 HTML 和导演 HTML。内容事实、原稿措辞和用户的单次修改要求始终拥有更高优先级。

## 视觉语言

- 内容页纸张：奶油白 `#FFFEFB`
- 封面或结尾的可选强调背景：暖柠檬黄 `#FFE477`
- 墨色：炭黑 `#222222`
- 辅助灰：暖灰，不使用偏蓝冷灰
- 少量辅助紫：`#D8D6FF`，只用于黄紫描边、对比或小面积结构强调
- 字体：`Xiaolai`，回退为楷体
- 线条：手绘感黑色线条，粗细明确但不笨重
- 阴影：默认无阴影；禁止厚重投影和大面积柔光
- 构图：低信息密度、清楚的视觉中心、留白有目的

## 内容忠实度

1. 完整读取原稿后再规划页面，不读一段做一页。
2. 保留原稿事实、结论、术语、数字和论证关系，不擅自改编。
3. 表格、步骤、清单和总结尽量沿用原稿的栏目名、顺序和文字，不为了版式重新发明内容。
4. 可以精简展示文字，但不能改变原意；字幕仍须按对应模式保留原文。
5. 不添加原稿没有提供的数量、状态、案例、更新日期或技术结论。

## 标题与强调

### 标题尽量保持一行

- 页面标题默认一行显示，先通过缩短展示标题、调整字号或扩大可用宽度解决，不随意手动换行。
- 只有标题在安全字号下仍无法放入一行，或原稿明确要求分行时，才允许换行。
- 不为了制造视觉节奏，把本来能放在一行的标题拆成两行。
- 避免只剩一个汉字、一个标点或一个很短的词落到第二行。
- 同一组连续页面的标题字号、基线和左右起点保持一致。

### 高亮文字与普通文字连续排版

- 非高亮标题和高亮标题之间不额外添加空格。
- 高亮片段必须像一句完整标题中的自然组成部分，不能产生肉眼可见的断裂。
- 中文标题不因拆成多个 `span` 而出现多余字距；英文与中文之间只按语义需要保留空格。
- 黄色下划线、高亮底色或紫色描边只选择一种主强调方式，不重复堆叠。

## 页面密度与对齐

- 一页只表达一个主要结论，辅助信息只为这个结论服务。
- 避免卡片下面或主体周围出现没有设计意义的大面积空白。
- 内容应在画面中形成完整的一组，不把主体挤在一侧，也不靠无效留白假装高级。
- 同组卡片顶部对齐、底部对齐；标题、图标、正文和入口在各卡片中使用一致基线。
- 横线、标题、列表、卡片和下方模块使用同一内容容器，左右边界必须对齐。
- 相关页面尽量复用相同网格、间距和视觉顺序，避免一页一套布局。
- 在 `1920×1080` 检查标题、边界、字幕和底部控件，不允许横向溢出、裁切或滚动条。

## 背景与色彩

- 仅封面页和最后一页可以按内容需要使用整页黄色背景，并非必须使用。
- 其他内容页统一使用 `#FFFEFB`，包括目录、数据、案例、步骤、步骤详情、转场、对比和总结前页。
- 黄色只用于关键词、标签、数字、按钮、短下划线和小面积节点。
- 辅助紫色只用于小面积对比、黄紫交替描边或必要的结构区分，不铺成大面积紫色背景。
- 禁止为了制造节奏，交替生成整页黄色、紫色或渐变背景。
- 禁止装饰性闪光、玻璃拟态、大面积柔光和荧光色。

## 步骤页

- 多步骤内容优先使用模板中的步骤页结构。
- `1–2–3–4` 或实际步骤编号固定放在页面顶部，所有步骤页的位置完全一致。
- 当前讲到的步骤高亮，其他步骤保持弱化，但仍清晰可见。
- 一页重点讲一个步骤；连续步骤页只替换当前高亮、标题和对应内容，不换布局。
- 编号格式服从原稿；默认使用 `1、2、3、4`，不要擅自补成 `01、02、03、04`。
- 步骤数量必须与原稿一致，不合并、不遗漏、不虚构额外步骤。

## 对比、表格与连续系列

- 表格优先保持原稿字段、行列顺序和原文内容，不把表格改写成泛泛卡片。
- 表格文字较多时，先调整列宽、字号和行距，不随意删改原文。
- 对比页保持左右等宽、标题同级、中间关系明确，结论只保留一条。
- 连续“转变 1、转变 2……”页面必须锁定标题、编号、箭头、前后状态和字幕位置。
- 同一系列只替换内容，不更换方向、色彩、卡片形状或整体构图。

## Logo、图标与图片

- 出现产品、模型、工具或平台名称时，优先使用其真实 Logo 或项目已有矢量资源，避免整页全是文字。
- Logo 尽量直接显示矢量图形，不再套无意义的椭圆、圆角胶囊或随机底框。
- 多个 Logo 使用统一的视觉高度和留白，不强行统一原始宽高比。
- 没有现成 Logo 时使用风格统一的线条图标，不使用随机 emoji。
- Logo 可使用模板已有的黄紫描边效果，但不能添加柔光或厚重阴影。
- 不临时搜索并使用来源不明、风格不一致的装饰图片。

## 人物形象

- Doodle Cream 中的卷卷姐形象统一使用项目现有头像，并采用圆形裁剪。
- 禁止使用全身商务小人、蓝领带人物、默认火柴人或来源不明的人物插画。
- 结尾页需要人物时，优先使用圆形卷卷姐头像，而不是重新绘制全身角色。
- 头像不拉伸、不压扁，圆形边缘保持清晰；可搭配手绘圆圈，但不叠加柔光。

## 封面与结尾页

- 封面无口播字幕，不创建空的 `.slide-subtitle` 占位。
- 封面主标题尽量一行；必要时缩小字号，而不是随意拆词。
- 封面的圆形紫底、审美标签或黄紫描边可以作为可复用 UI 元素，但必须服务主题。
- 结尾页总结使用原稿已有章节标题或核心结论，不重新编造总结。
- 结尾链接只显示真实存在且用户指定的入口；链接文字简洁，不堆砌标签。

## 字幕与文案

- 字幕与画面标题分工明确：画面标题可以精简，字幕保留对应口播原文。
- 封面没有字幕；第一句口播从封面后的页面开始。
- 中文标题中的逗号、顿号和分号通常不进入大字标题，但字幕不得因此改写。
- 不让字幕遮挡页面主体；关闭字幕后不保留空白占位。
- 相邻页面的字幕不能遗漏、重复或前后错位。

## 动效

- 演讲 HTML 以轻微淡入、上移和重点强调为主，不自动跳页。
- 导演 HTML 实现稿件要求的实际动效，不在画面中显示“淡入”“转场”等制作说明。
- 连续页面的动效节奏保持一致，不因换页随意更换动画风格。
- 尊重 `prefers-reduced-motion`；减少动态效果时内容必须完整可见。
- 禁止无意义弹跳、闪烁、粒子、装饰性发光和过度缩放。

## 禁止项

- 能放一行的标题被随意拆行。
- 高亮文字与普通标题之间出现多余空格。
- 单个汉字、标点或极短词孤零零落到下一行。
- 为了填满页面而添加虚构信息。
- 全身默认人物代替圆形卷卷姐头像。
- Logo 外面统一套椭圆或随机胶囊。
- 内容页整页黄色、紫色、渐变或柔光背景。
- 卡片垂直居中导致上下大片空白。
- 同一系列页面每页换一种布局。
- 修改原稿表格、步骤或总结的原意。

## 交付前检查

1. 逐页检查标题是否能保持一行，以及是否出现孤字落行。
2. 检查高亮与非高亮标题之间是否存在多余空格。
3. 检查所有非首尾页面的实际背景色是否为 `rgb(255, 254, 251)`。
4. 检查同组页面的标题、横线、卡片和内容左右边界是否对齐。
5. 检查步骤页顶部编号的位置与高亮状态是否一致。
6. 检查表格、Logo、总结和字幕是否忠于原稿，没有擅自改编。
7. 检查人物是否只使用圆形卷卷姐头像，没有残留默认全身小人。
8. 在桌面端和窄屏检查溢出、裁切、遮挡、卡片不齐和无意义空白。
9. 检查方向键、空格、Home/End、触摸、按钮、页码、进度条和字幕开关。

## 与首页生成器的关系

`design.md` 是 Doodle Cream 的长期设计手册，供使用者与 Agent 阅读。首页生成器仍会另外传入完整 `template.html`、当前配色变量以及通用字幕、转场、对比和生成规则。若首页生成器中的硬规则与本说明不一致，应同步更新生成器规则，避免文档与实际输出分离。
