# Handdrawn Yellow

一套带人物插画、编号信息卡与黄色满版页面的手绘演示系统，不继承 BlockFrame 的结构或视觉语言。

## 视觉语言

- 纸张：纯白 `#FFFFFF`
- 墨色：炭黑 `#222222`
- 强调黄：暖柠檬黄 `#FFE477`
- 辅助底色：白色 `#FFFFFF`
- 字体：`Xiaolai`，回退为楷体
- 线条：4–5px、不规则圆角、无投影
- 构图：大留白、低信息密度、每页一个视觉中心

## 使用原则

1. 一页只表达一个结论。
2. 黄色只用于最重要的词或节点。
3. 辅助信息使用白底黑框，不使用紫色。
4. 不使用硬阴影、粗重面板、荧光色和新野兽派结构。
5. 动效保持轻微淡入与位移，不抢内容。
