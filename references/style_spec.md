# 风格构图规范（人读参考）

> 机读结构见 `references/styles.yaml`；本文件保留 YAML 中没有的**构图细节**（比例、位置、装饰语法）。
> 总原则：先匹配参考图的「视觉结构」，再填内容；不同风格不混用；颜色/构图/层级/装饰必须稳定。

## 01 · MFLEX 蓝白项目汇报 `weekly_report_mflex`

- 画布 16:9，白底，四周极细浅蓝灰边框。
- 顶部深蓝横幅，高度约占 12%–14%；左上白色大标题（字重 700），右上 `MFLEX` 标志。
- 主体为两列两行**四象限**，不要做成独立浮动卡片。
- 模块标题格式 `一、项目目标`，标题下有同色蓝色细横线。
- 底部浅蓝**波浪**占底部 18%–22%；最底部深蓝页脚条，右侧页码 `01 / 08`。
- 避免：大面积渐变卡片、强投影/发光/毛玻璃、圆角卡片、橙紫主色、省略波浪。

## 02 · 暗金数据洞察 `dark_gold_insight`

- 暗色圆角矩形，背景近黑棕；外圈 1px 暗金边框，四角短线角标；叠轻微颗粒纹理（非纯黑）。
- 顶部居中大标题（金白、字距略大），标题与英文副标题上下加金色细线 + 菱形装饰。
- 主体**三栏**：左金「主观 · 洞察」/ 中青绿「筛选 · 过滤」/ 右紫「建模 · 预测」；栏间金色细竖线。
- 每栏背后有对应色柔和径向光晕（左金 / 中青 / 右紫）；底部金色分割线 + 三组元信息。
- 避免：只做黑底金字（须保留青紫信息区）、大块纯金填充、现代仪表盘卡片、大圆角白卡、正文纯白。

## 03 · Raw Paper 文本笔记 `raw_paper_notes`

- 背景偏米白（非纯白），可加轻微扫描纹理。
- 左侧超大黑体标题，左上可加低可见度白色水印文字。
- 右侧大白色展示面板（轻投影）；面板内左侧一张**倾斜纸张**（黑色描边 + 粗糙线条）。
- 背后叠棕 / 淡黄 / 深灰色块体现拼贴感；右侧三组信息 `PRIMARY MOVE / SURFACE BEHAVIOR / VISUAL SIGNATURE`。
- 标签用白底胶囊 + 轻微阴影。避免：过度规整、蓝紫橙高饱和、玻璃/发光/科技渐变、纸张太干净。

## 04A · 自媒体 V2a 层叠卡片封面 `social_card_layering_v2a`

- 左右分栏，左文右大白面板；背景浅粉米→浅蓝柔和渐变（别太淡到没颜色）。
- 左侧小号蓝紫 kicker（如 `GENERAL STYLE 28 / 49 · SOURCE #46`）；主标题超大黑色英文，两行。
- 右侧面板占约 48%–52% 宽，白底大圆角柔投影；左上蓝青渐变圆点。
- 面板内左侧浅桃色大色块，叠白 / 橙(`#ff7416`) / 蓝紫矩形（蓝紫须高饱和）；右侧三段信息，首段在浅桃卡片内。
- 避免：蓝紫/橙调淡、普通数据卡片、右侧面板过小、中文说明过多（原图偏英文视觉封面）。

## 04B · 自媒体 V2b 仪表盘信息流 `social_dashboard_v2b`

- 顶部左标题（左加橙色竖线），右侧日期与负责人。
- 第一行**四个指标卡**（白底细边框轻投影，数字橙色）。
- 第二行左「项目进度卡」含橙色**环形进度**；右「近期动态列表」（细线分隔）。
- 底部项目信息栏：编号 / 状态 / 版本 / 环境 + 设置图标。避免：促销海报感、过度装饰、大面积渐变。

## 05 · Aurora UI 极光科技 `aurora_ui`

- 背景深蓝 / 黑紫 / 墨绿**多层渐变**；左侧超大白标题 `Aurora UI`，左上低饱和白水印，kicker 亮青。
- 右侧半透明大面板（大圆角 + 柔光）；内部青 / 粉 / 蓝半透明重叠形状形成极光流动。
- 右侧三张半透明玻璃信息卡（文字白 + 青）：`mesh gradients / luminous blend / slow atmosphere`；胶囊标签半透明非实心。
- 避免：单一紫背景、普通商务卡片、削弱粉/青发光、画面过亮（须保持暗色沉浸）。

## 生成后自检（速查）

1. 远看能否立刻认出参考风格。
2. 主色是否匹配、不偏淡/偏灰/串色。
3. 构图是否一致：MFLEX 四象限 / 暗金三栏 / V2a 左文右面板 / V2b 仪表盘 / Aurora 左文右玻璃。
4. 关键识别元素是否出现：波浪 / 金线 / 纸张 / 层叠色块 / 极光。
5. 是否误用其它风格元素。
6. `file://` 下是否可独立打开、无外部依赖。
